# C08 - Structures, Macros & Headers
## Description
This module wraps up basic types and structures in C, using headers, macros, and small structs before combining them into functions that work together.
## Concepts Covered
- Header files and function prototypes
- Preprocessor macros
- Custom types (booleans, points)
- Structures (t_stock_str)
- Dynamic arrays of structures
## Objectives
- Organize prototypes in headers
- Write correct, norm-compliant macros
- Define and use custom structs
- Build and display an array of structures
## Notes
Norminette must be run with the -R CheckDefine flag.
